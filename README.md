# elindependiente
El Independiente 2030 es una aplicación web interactiva que presenta el plan de transformación digital 2026–2030 del diario riojano. Propone evolucionar hacia una Plataforma de Conocimiento Público, integrando periodismo de datos, contenidos transmedia, audiencias propias, IA, UX, archivo histórico y un modelo financiero sostenible.
