Transparencia Técnica y Privacidad

Audio V4 procesa el audio localmente utilizando las Web APIs nativas del navegador. La Web Speech API utiliza el motor de reconocimiento integrado del navegador (el cual puede enviar audio a servicios locales o en la nube del fabricante). Para archivos de audio, se emplea Web Audio API para normalización PCM. No se requieren claves de API externas ni se almacenan archivos pesados en servidores.
